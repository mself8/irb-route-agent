# 지표 (가상 계획서 10건 · T3 확인 전 초안 · 프롬프트 조정에 쓴 샘플 2건 제외 · 반복 5회)

| 지표 | 값 | 뜻 |
|---|---|---|
| 경로 일치율 (규칙 엔진) | 100% | 정답 사실을 넣었을 때 경로가 맞은 비율 |
| 경로 일치율 (전체) | 100% | 추출한 사실을 고치지 않고 확정했을 때 |
| 필수 판단불가 재현율 | 100% | 넘겨야 할 항목을 넘긴 비율 |
| 부당 기권 | 0건 | 정해진 답이 있는데 판단불가로 넘긴 수 |
| 기권율 | 36% | 판단불가 행 / 전체 판정 행 |
| 사실 추출 정확도 | 87% | 채점 대상 사실의 값 일치율 |
| 인용 정확도 (모델 원출력) | 100% | 원문과 글자 그대로 맞은 인용. 틀린 인용은 화면에 나가지 않음 |
| 5회 반복 일치율 (경로) | 100% | 같은 계획서를 5번 돌려 경로가 모두 같은 비율 |
| 건당 처리 시간 | 31초 | 마스킹·추출·판정·질문 작성 |
| 관할 유형 일치 (CRIS 실제 연구 8건) | 6/6건 | 소속 기관 IRB가 승인한 연구에서 같은 위원회를 고른 수 |
| 다른 기관 IRB 승인 연구 | 2/2건 확인 요청 | 명단에 없는 관계는 추정하지 않고 연구자에게 물음 |

## 읽는 법과 한계

- 측정 기준 커밋: 11cc8ec (규칙 엔진은 1ca4138 기준). 이후 수정분은 다시 재야 한다: `python eval/metrics.py 5`
- 가상 계획서 10건과 정답은 우리가 만들었고 T3 확인 전이다. 건수가 적어 100%가 곧 "틀리지 않는다"는 뜻은 아니다.
- 사실 추출 오답(13%)은 대부분 계획서에 적히지 않은 사실을 모델이 '아니오'로 추정한 경우다(예: 설문 연구의 인체유래물 사용).
  경로를 바꾼 오답은 없었다. 이런 추정은 ④ 사실 확인 화면에서 사람이 고친다.
- CRIS 관할은 "유형" 일치다. 소속 기관에 IRB가 있다는 사실은 같은 CRIS 기록에서 명단에 옮겨 넣었으므로,
  IRB 존재까지 맞힌 것은 아니다. 소속 IRB·공용위원회·임상시험 경로·확인 요청 중 무엇을 골랐는지를 본다.
- 통과 여부는 재지 않았다. 승인 예측이 아니라는 원칙 때문이다.
