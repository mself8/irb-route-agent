# data

| 폴더 | 내용 | 담당 |
|---|---|---|
| `samples/` | 데모 샘플 2건(가상 계획서 + 예시 결과). FAKE 모드와 자리표시자 노드가 쓴다 | 송윤 |
| `rules/` | 규칙표 YAML. 판정은 이 파일만 보고 한다 | T1 · 송윤 |
| `lists/` | 공공 명단 CSV (IRB 인증 기관, 임상시험 실시기관) | T3 |
| `schedules/` | 공개 심의 일정 (회의일 · 접수 마감) | T3 |
| `laws/` | 근거 검색용 법령·가이드라인 원문 (정리한 md) | T1 |
| `cases/` | 테스트용 가상 계획서와 정답 라벨 | T3 |

- `lists/*.csv`는 열을 맞춘다: `기관명,IRB_등록,IRB_인증,임상시험실시기관,출처,확인일` (값은 예/아니오). ⑤ 기관 대조가 모든 파일을 읽는다. `demo_institutions.csv`는 데모용 가상 기관이다.
- 파일마다 출처 URL과 확인일을 적는다.
- 저작권 표시가 있는 기관 원본 문서(PDF 등)는 올리지 않는다. 정리한 내용과 출처만 올린다.
- 실제 개인정보는 넣지 않는다. 계획서는 전부 가상으로 쓴다.
