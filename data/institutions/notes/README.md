# 기관 조사 기록

기관마다 `<id>.md` 하나. 프로필(`../profiles/<id>.yaml`)의 근거를 적는다.

- 확인일, 조사한 공식 페이지 URL 목록
- 찾은 것: 제출 창구, 제출 서류(신규·심의면제), 심의면제 절차와 대상, DRB 선행 여부, 교육 이수 요건, 회의 주기·접수 마감·결과 통보, 계획서 서식 항목, 기관 고유 규칙
- 못 찾은 것: 로그인 필요, 비공개, 페이지 없음
- 인용은 사실 확인에 필요한 짧은 구절만 (원문 파일은 레포에 넣지 않는다)

사전 조사(본선 전, 09-29)로 만든 공용위원회·서울시립대·서울성모병원·질병관리청은 `prep/institutions/`의 정리본이 근거다.
